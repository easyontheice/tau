# Tau 1.0.7

A maintenance release in response to the Obsidian community review. Nothing about how the timeline looks or behaves changes.

## Fixes
- Frontmatter is now type-checked throughout. A property with an unexpected type, such as a number in `color` or a list where text is expected, can no longer break the timeline.
- Fixed a crash when a node's `color` was a plain number (for example `color: 000000`).

## Project
- Release files now carry GitHub build-provenance attestations, so you can verify they were built from this repository.
- The readme gains a **Privacy & Data Access** section explaining exactly what Tau reads and writes. Tau makes no network requests.
