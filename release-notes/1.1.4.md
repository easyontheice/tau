# tau 1.1.4

## New
- **Randomize colors.** Right-click the canvas to give every event, span and left span a random color from a built-in palette: light colors for events and spans, dark colors for left spans. Right-click a node (or a selection) to recolor just those. Every color is used once before any repeats, and linked successors and parents never share a color. Only the `color` property changes; title and date colors are left alone. Tau asks before overwriting anything.
- **Date text size.** Two new options set the size of the dates on all spans or all left spans at once (default 10 px, range 6–40). Find them in the right-click menu (**Span date text size...** / **Left span date text size...**) or in the plugin settings.
- **Global importance.** Three new settings (**Event importance**, **Span importance**, **Left span importance**) enlarge or shrink the text of every event, span or left span at once. They add to each note's own `importance` without changing your notes, and minor-node hiding is unaffected.
- **Plugin settings.** Tau now has a settings page (**Settings → Community plugins → tau**) with the CSV import, the date text sizes and the global importance settings.

## CSV import
- **Import from settings.** Choose a destination folder and a CSV file, then select **Import CSV**. The import in the right-click menu and the command palette works the same way.
- **Subfolders from a column.** Use `{{column}}` in the destination folder, for example `Timeline/{{region}}`. Rows with a blank value go in the parent folder. A misspelled column name stops the import before anything is written.
- **Every column is kept.** Timeline columns get the right types; any other column becomes a text property with the same name. A `description` column becomes a property and is also written into the body of new notes, so it shows in the reader.
- **Much faster on big files.** Open timelines pause reloading during the import and refresh once at the end, and each new note is written in a single step.
- **More robust parsing.** Quoted cells can now contain line breaks (multi-paragraph descriptions), and CSV files saved by Excel are read correctly.
- Re-importing onto existing notes still only merges the non-blank values into their properties. Note bodies are never changed.

## Improvements
- Auto-scatter also pauses timeline reloads while it runs, so large timelines stay responsive.
